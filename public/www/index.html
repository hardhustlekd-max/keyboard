📲 How to Install & Enable on Android

  1. Download the AmharicKeyboard.apk file using the button above.
  2. Open the downloaded APK on your Android device and confirm installation (allow "Install from Unknown Sources" if prompted).
  3. Go to Android Settings > System > Languages & Input > Keyboards.
  4. Enable Amharic Keyboard in the list of available soft keyboards.
  5. Open any app (WhatsApp, Messages, Notes) and tap the keyboard switcher icon to select Amharic Keyboard!
